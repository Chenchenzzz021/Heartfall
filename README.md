# Hearthfall

Game xây thành trung cổ chạy trên trình duyệt. Mở `index.html` (cần thư mục `assets/` bên cạnh).

Triển khai: trang tĩnh, không cần build. Trên Vercel chọn Framework Preset "Other", để trống Build Command và Output Directory.

Hình ảnh: xem [CREDITS.md](CREDITS.md).

## Deploy
Every push to main triggers the Vercel deploy hook via .github/workflows/vercel-deploy.yml (secret VERCEL_DEPLOY_HOOK).
